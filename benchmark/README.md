## 使用约定

- 不由本项目自行打分，不跨评测相加、平均或补分；同一来源的排名保留原有顺序。
- 按具体 API、模式和模型组合引用成绩；同品牌的不同端点、付费与免密路径不能自动共用分数。
- “未评测”或“未取得公开分数”不等于零分、失败或排在末位。
- 搜索答题准确率、抓取可达率、正文质量是不同指标，不合成一个总榜。
- 索引是带日期的外部结果快照，不自动同步代码中的默认路由权重；更新时需同时核验来源、配置和供应商覆盖。
